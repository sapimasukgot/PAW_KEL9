📋 Cek Pesanan Terakhir

Buka browser dan akses: http://localhost:8000/penjual/pesanan-detail/[order_id]

Apa yang Harus Dilihat:

  • ✅ Jumbo muncul dengan qty > 0 (jika ada porsi jumbo)
  • ✅ Harga topping tidak 0 (jika ada topping dengan harga)
  • ✅ Subtotal benar = qty × harga

📝 Langkah Test:

  1. Buka http://localhost:8000/pembeli/
  2. Klik order menu (misal: Nasi Goreng)
  3. Isi:
    • Reguler: 2 porsi
    • Jumbo: 3 porsi
    • Topping: Pilih salah satu (misal Telur)
    • Level Pedas: Pilih Lvl 1
  4. Klik Bayar
  5. Lihat di penjual/pesanan untuk lihat order detail
  6. Cek apakah jumbo dan harga topping muncul ✅

📊 Kalau Masih Tidak Muncul:

Cek di DevTools Browser (F12) → Console untuk lihat error JavaScript
